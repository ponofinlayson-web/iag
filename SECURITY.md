# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.3.x   | yes |

## Reporting a vulnerability

We take security reports seriously. IAG is an identity and access governance
product - vulnerabilities in authentication, audit integrity, or access
enforcement are treated as critical.

**Do not open a public issue for security problems.**

Instead, use one of these channels:

- **GitHub private vulnerability reporting** (preferred): Security tab ->
  "Report a vulnerability". Enable it via repository Settings if it is not
  yet active.
- Email: security@iam-simplified.com

Please include:

- The component and endpoint(s) involved
- Steps or PoC to reproduce
- Impact assessment (what an attacker gains)

You will receive an acknowledgment within 72 hours. Fixes for accepted
reports ship in a patch release, and the reporter is credited in the release
notes (opt-out available).

## Disclosure timeline

- Day 0: report received, acknowledged
- Day 0-7: triage and severity assignment
- Fix targeted for 30 days or sooner for critical issues
- Coordinated public disclosure after the fix ships
